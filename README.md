# Monpupitre — le site publié

« Le site qui ne fait pas tes devoirs à ta place. »

→ **https://luminophaure.github.io/monpupitre-site/**

Ce dépôt ne contient que les fichiers nécessaires au site, publiés par GitHub Pages.
Il est **fabriqué automatiquement** : ne pas y modifier un fichier à la main, la
prochaine publication l'écraserait. Le travail se fait dans le dépôt privé, d'où part
la commande `python3 tests/publier_site.py`.
